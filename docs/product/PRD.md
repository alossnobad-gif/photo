# 自然图鉴 PRD

版本：1.0 基线；更新：2026-10-29；初始代码基线：a4c2a92，后续变更见台账。

## 目标和使用者

为用户本人长期使用的摄影平台，先持续使用半年至一年，逐步提高稳定性。主要在电脑上使用，也支持手机。用户使用索尼 A7R V，相机会同时保存 RAW 和 JPG；两者均可独立导入。商业多租户、计费、公开分享社区不属于当前已确认范围。

核心价值：整理自己的照片、基础修图、识别物种、记录风光足迹。现有真实照片和手动核实的资料是需要保护的资产。

## 信息架构

侧栏：图库与修图、图鉴收藏、风光足迹、探索记录、识别队列、识别设置。

不恢复单独的拍照识别菜单，不加入示例照片或“我的收藏”重复分类。其他页面已有上传和图库选片入口保留；修改入口前检查所有提交路径。

## 图库及修图流程

1. 单张或多张导入 JPG/PNG/WebP/TIFF，以及解码器支持的 RAW；图库单张限制 150 MB，独立图鉴/风光上传限制 50 MB。Nginx 请求上限需覆盖 150 MB 文件及请求开销。
2. 保留中文文件名；可搜索照片、按 RAW/JPG/已修图、提交状态筛选，按上传时间排序。
3. 相机照片读取 EXIF 机身、镜头、光圈、快门、ISO、焦距；图库、图鉴及风光缩略图下沿两行渐变信息条展示，不写入照片像素，不影响识别。只有真实存在的参数才显示；缺失时不猜测。导入/裁切前保存设备信息，图库覆盖保留，新字段可选；历史照片优先读取尚存原件。
4. 默认显示“未提交”；所有提交范围中表示物种和风光均未提交。切到其他页面再返回，仍能加载照片，不能把加载失败当成空图库。
5. 修图支持原图比例、自由/固定比例裁切、移动裁切框、旋转、翻转；曝光、对比度、高光、阴影、白黑色阶、自然饱和度、饱和度、清晰度、色温、色调。
6. 预设：原色、自然通透、鸟羽细节、森林清新、山川层次、暖色日落、冷调晨雾、胶片柔和、经典黑白；可调强度并继续微调、对比、重置。
7. 电脑编辑使用宽窗口，预览和调整区左右布局；手机适配，不能为手机改坏电脑体验。竖图完整预览。
8. 图库编辑保存覆盖当前照片，保持记录 ID 和照片路径、拍摄日期；清理不再被引用的原件，避免自动生成多份图库成片。直接上传时先裁切，再上传裁切结果进行识别。
9. 图库勾选后明确选择“识别物种”或“识别风光”。不能依据上一次状态猜测类型。收到服务器任务 ID 和类型才算提交成功。
10. RAW 修图基于解码后的 8 位 sRGB 图像；不承诺专业 RAW 全动态范围、图层、蒙版或 Lightroom 全部功能。RAW/JPG 不自动配对。


## 识别与入库

- 批量上传入口区分“从图库批量选择”和“选择多张照片”：电脑等高并排、手机上下排列，原生文件控件隐藏但支持多选；两条路径分别验证物种/风光类型。
- 物种与风光分别使用明确接口和不同提示词。同一照片的两类提交状态独立，不得错投类型。
- 文件名作为不可信线索提供给模型，不能执行文件名中的指令，不直接作为物种/地点事实。
- 拍摄日期以 EXIF 为先，缺失时可手填；模型不能猜测日期。上传、入库和拍摄时间是不同字段。
- 队列默认展示“处理中与待确认”，可切换待确认、已入库或全部；任务类型默认全部类型。
- 队列持久化，关闭浏览器继续处理；默认一次处理一张。启动恢复中断任务。
- 模型返回 0–1 的有效置信度，严格大于 0.85 才自动入库；恰好 0.85、缺失、格式无效或物种不确定进入待确认。物种还须名称、学名等有效。UI 按分显示并四舍五入，所以显示 85.0 分并不必然表示原值等于 0.85。
- 同种的不同照片不自动覆盖，重复冲突进入待确认；用户确认替换后保留最初入库身份和发现时间。
- 识别超时/失败可使用原照片重试，不重新上传。识别模型调用关闭已明确支持的默认深度思考，减少无必要推理延迟；调用超时上限 120 秒，不把文字测试速度等同于图片识别速度。
- 支持停止单任务、停止全部、继续、删除队列记录和批量删除。停止后晚到结果不得入库；删除队列不删除已入库或图库引用的照片。保存中的任务不能被随意删改。
- 手动确认失败显示错误、保留待确认结果，不能因前端等待超时制造重复记录。已完成确认应幂等。
- 成功完成的物种进入图鉴，风光进入风光足迹；图库同步对应状态，不能要求用户等待全部图片下载才完成提交或删除。

## 图鉴与探索记录

- 分类：鸟类、动物、植物、昆虫、菌类；观测稀有度与法定保护等级分别存储和展示。
- 保护等级依据离线公开名录匹配，优先于模型猜测；不匹配或矛盾结果不强行认定。人工核实资料需保留来源标记，不能被无说明重匹配覆盖。
- 支持人工编辑名称、学名、分类、稀有度、保护等级、介绍、栖息地、备注和日期；编辑不能偷偷替换照片或发现时间。
- 支持名称/学名搜索、拍摄时间/入库时间/稀有度/保护等级排序，探索记录按已有收藏展示。
- 已解锁物种统计去重，展示常见/稀有、各分类和保护等级；探索进度使用个人目标，不声称覆盖全国所有物种。
- 分享先配置再生成：分类、具体物种搜索/勾选、保护等级和稀有度筛选，拍摄/入库/保护/稀有度等排序；可修改海报标题。封面可选择已收藏照片，或本地 JPG/PNG/WebP（最大 50 MB），不上传服务器。
- 无独立封面时展示排序后的前六种；有封面时展示前三种与独立封面。统计及配文以本次筛选并勾选的所有物种为准，封面不计数，明确提示展示数量。更改配置后旧海报失效，重新生成才能下载。空选禁止生成。海报逐张加载缓存预览，不批量下载原图；失败指出具体照片或封面名称，可重试。
- 可下载海报、复制配文及条件允许时系统分享，自行发布到小红书等平台；不自动发布社交媒体。

## 风光足迹

- 题材：山川、河流、湖泊、海岸、森林、草原、沙漠、戈壁、日出日落、云雾星空、城市风光、建筑地标、其他。
- 专用模型回复标题、题材、景观描述、分享文案、地点候选、置信度及依据；识别明确地标、城市、省份，已知城市用行政映射补全省份。
- 无定位或地标证据不足允许待整理，不用模型臆测充当已核验事实。候选可以核实后采用，入库后可人工编辑。
- 顶部展示省份、城市、地标进度，城市/地标目标是个人目标，不能伪称全国总数。地区/地点计数去重，未知值不算解锁。
- 按地点/题材筛选、标题/地点搜索，卡片尺寸整齐，列表加载缩略图，详情保留完整照片。
- 不展示独立的大幅顶部地点相册或卡片外悬浮删除按钮；删除入口在照片详情底部。删除风光记录保留图库及图鉴引用照片。
- “错误风光改为物种识别”是临时数据修复入口，已撤下；未获得恢复授权前不重新加入。

## 百度网盘（首版）

个人应用官方 OAuth 授权，服务器保存密钥/令牌。图库入口配置、连接、手动目录分页读取、显式选片导入；宽窗口默认平铺缩略图，可切换列表；电脑选片/预览左右布局、手机上下布局。点击缩略图放大，↑↓及←→按本页照片顺序切换、跳过目录与不支持的文件，高亮并滚动到当前项；输入框编辑时不触发切图。电脑左右分隔线可拖拽或键盘调整比例（25%–70%）；网盘预览可选适应窗口、100%/200%/300%及10%–800%自定义，单击在适应和最近比例间切换，拖动画面不触发缩小；切图保留比例。百分比以网盘预览图像素为准，标注实际分辨率，不伪称为相机原图细节。预览导航不改变勾选，换目录/页码清空原预览，预览不触发选择或导入，百度缺失缩略图时显示占位且仍可选择。预览服务器代理并缓存，不回传令牌或签名下载地址，不为预览下载整张原图；不扫描整个账号，不删除网盘文件，不自动识别。复用已有图库流程、150 MB 限制及元数据；远端文件 ID 去重。清除本地连接保留导入照片，彻底撤销需百度端操作。当前不是后台实时同步；分享链接路线暂停，官方真实权限/下载需线上验证。详见 ../baidu-drive.md。

## 数据、安全和发布规则

现有持久化为 JSON 文件和照片文件，不是数据库事务系统。各存储内部使用串行、临时文件、原子重命名；跨集合操作仍须单独考虑失败和恢复。

| 数据 | 作用 | 不可混淆的规则 |
| --- | --- | --- |
| baidu-drive.json | 网盘应用凭据与授权令牌 | 服务器私有 0600，备份保护，不回传或打印 |
| library.json | 图库索引、上传时间、编辑配方 | 图库删除不等于收藏删除 |
| collection.json | 去重物种收藏 | 学名去重；首次发现时间不随替换改变 |
| landscapes.json | 风光资料与地点 | 同一照片可同时用于其他模块 |
| recognition-queue.json | 任务、结果、已保存记录 | 完成不等于可以删除照片；不要嵌入整个相册快照 |
| photo-equipment.json | 相机/镜头及拍摄参数侧车索引 | 元数据可选；部署与备份保留，不把水印烧入照片 |
| photos/ | 原有照片或可编辑渲染图 | 保持引用路径稳定，清理前核对所有集合 |
| library-originals/ | 未编辑原件 | 下载需鉴权；覆盖编辑后按引用清理 |
| photo-previews/、queue-thumbnails/ | 可重新生成的缩略图 | 不能替代备份原照片；修图后失效更新 |
| library-deleted-photos.json | 删除标记 | 避免启动索引把已删除照片重新导入 |
| recognition-settings.json 等 | 设置及敏感信息 | 禁止打印密钥、提交 Git 或打入源码包 |

- 部署保留整个 .data、服务器环境配置、服务账户权限。不能用临时目录的权限覆盖项目目录。
- 当前是个人单账户、Nginx Basic Auth；HTTPS 为自签 IP 证书，浏览器不信任警告仍存在。不是独立管理员角色系统。
- 自动更新已取消，用户手动更新。源码提交、服务器更新、线上验证三者分别记录。
- 删除必须明确对象、保留引用照片；涉及批量数据迁移先备份、预览影响，失败可恢复，不删除所有历史记录作为“修复”。
- 不能以同盘备份或 Git 仓库代替照片异地备份；当前无已验证的自动灾备。

## 体验及验收要求

电脑及手机都要验证。模块切换重复三次仍可加载；请求失败展示错误/重试，不能永久显示加载中。列表不批量请求原图；详情再获取原图。缓存缩略图能从 .data 隐藏目录发送且编辑后更新。空闲轮询减频，后台暂停；正在识别保留快速同步。

尚无真实线上耗时基线，不能承诺所有页面一秒完成。后续记录首屏数据响应、首张可见图、错误率，区别服务器耗时、网络传输和模型调用。


重复物种在队列待确认中展示原有／本次照片对比，用户明确点击“替换为本次照片”才覆盖；保留原记录 ID 与首次发现日期，采用本次拍摄日期。“暂不替换”保留待确认任务。兼容旧任务，替换前核对当前照片，发生并发更新则要求重新对比。


## 2026-10-18：大屏、筛选选择与风光去重

- 主内容区随可用屏幕宽度铺开，取消 1600px 上限，保留现有手机断点和侧栏。
- 风光支持拍摄日期起止范围，包含边界，可单独指定一端；与城市、题材、搜索叠加。启用日期范围时不包含日期缺失记录，清除日期后恢复。此处按 takenAt 拍摄日期，不按上传时间；顶部进度仍统计全部足迹。
- 图库“全选当前筛选结果”覆盖搜索、照片类型、提交状态及状态范围的交集，显示已选数量、部分选中状态、取消全选和清空选择。批量识别只提交当前可见且选中的照片；筛选后隐藏的选择不参与提交。
- 风光新增入库按稳定照片路径或文件 SHA-256 去重，返回已有记录和原 ID／日期／人工资料，不追加、不覆盖。相同城市／标题的不同文件仍可保存。写入串行化防止并发重复。校验文件大小后再流式计算内容摘要，缓存按文件大小与修改时间失效，不扫描读取所有不同大小的原图。
- 去重适用于后续保存，包括队列自动与手动入库；不删除已有重复记录，不清理上传文件。不同压缩、裁切或 EXIF 的版本未做视觉相似度判断。


风光排序补充（2026-10-18）：保留日期筛选，增加“最新拍摄／最早拍摄”，默认最新拍摄；以 takenAt 排列，缺失或无效拍摄日期在两种方向均排最后，同日保持原顺序。记住当前浏览器的排序选择；与日期、城市、题材、搜索共同生效，不修改入库记录或顶部统计。

## 2026-10-18：自动／手动识别与提示词帮助

- 图库选片、单张物种／风光、批量上传可选择千问自动或手动粘贴。同一批照片共用当前选择，不逐张弹出询问。默认自动，可在当前浏览器记忆选择；每个入口提交前明确展示。
- 手动无需千问配置，生成持久化 review 草稿，显示“待填写／核对”和文件名；不调用模型，不因高置信度自动入库。到队列逐张粘贴对应照片的结果并核对确认。不支持批量 JSON 数组，不把一份结果套用给所有照片。
- 支持纯 JSON 对象、代码块、kind/result 包装和常见中文字段。按类型校验白名单；错误保留原文和表单。照片路径、ID、拍摄日期、GPS、首次发现及 replace 不可通过 JSON 覆盖；拍摄日期继续使用 EXIF／用户填写。
- 草稿服务端持久化，保留名录核对、重复物种明确替换、风光去重、城市省份补全。自动待确认可粘贴结果，失败／停止任务可转手动；中止在途识别，晚到结果不得覆盖手动填写。已发出的调用可能已有费用。
- 手动任务普通恢复不调用模型；只有明确选择自动或点击“改用千问识别”才进入自动识别。已完成任务不能通过粘贴端点直接改写。
- 侧栏独立“识别帮助”，无需上传便可复制物种／风光提示词；方式控件提供帮助，粘贴处提供模板。自动复制受限时可选择文字手动复制。帮助说明完整流程、日期规则及批量边界。

## 2026-10-20：图库批量删除与空间清理

- 在图库“全选当前筛选结果”旁增加批量删除。只处理当前筛选下选中的 ID；确认窗口冻结本次文件名列表，取消不发删除请求，不扩大到隐藏选择。
- 删除图库记录、对应非进行中队列历史及无其他引用的原件、预览、缩略图。图鉴／风光记录及其图片、其他图库共享文件保留，本地电脑与百度网盘不变。不是只删除原件并保留全部图库预览的功能。
- 排队／识别／保存／确认中的照片跳过并显示数量。清理期间对照片加保留锁，防止新队列任务与文件删除交错。删除标记防止重启后把图鉴照片重新导入图库。
- 服务端每批一次元数据写入、一次批量历史清理及一次引用读取，不读取解码图片；客户端每 500 张一批，有进度，重复请求按缺失 ID 处理，失败可重新核对重试。已删 ID 过滤迟到的轮询，避免已删除卡片重新出现。
- 按成功移除文件的字节数汇总释放空间；读取引用或文件清理失败时保留文件并明确提示部分空间未释放，不伪装全部清理成功。不会扫描未知孤立文件或清除图鉴／风光图片缓存。
