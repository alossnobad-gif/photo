## API 路线的前置条件

官方平台入口：https://pan.baidu.com/union 。需要用户通过百度页面创建应用，并确认申请、审核、文件读取/下载范围和当前个人应用条件。当前文档页面受开发网络阻挡，尚未独立核实最新审核要求；不承诺所有个人账号立即开通。

应用配置、授权回调和 Secret 通过服务器环境或受保护配置提供，不能放在聊天、前端、源码仓库或日志。账号本人完成百度授权；程序不接收百度登录密码。正式接入前核实实际范围、短期下载地址、刷新令牌、分页、速率及退出授权机制。

读取路径：授权 → 列目录 → 用户选择照片 → 下载临时文件 → 复用图库验证/导入 → 保留日期/设备元数据 → 用户明确选择物种/风光队列。只读网盘，不删除或覆盖源文件。服务器原件保留策略需与用户最新需求单独确定，不能顺便清理全部历史原件。

## 分享链接路线

用户已提供测试分享及提取码。仅验证该分享范围，不扩大到完整账号。网页可能要求登录/验证码、短期地址、限速；不能承诺每个链接能被后台稳定自动下载。

没有官方支持的通用匿名分享下载保证。若只能通过用户浏览器手动下载，明确说明这不等于平台自动导入。不要使用盗取 Cookie、绕过验证码、未授权第三方解析服务或把提取码发送到第三方。

## 正常提取码提交检查

用户确认浏览器可打开，四位提取码自动填充，等几秒进入分享。此前 curl 只返回提取码页，不执行页面 JavaScript，不能认定链接打不开或必须安全验证码。新增 scripts/check-baidu-share.py，用户服务器执行：先 GET 建立内存会话，再向分享网页的 verify 路径提交用户提供的提取码，再只读获取分享页。此为网页流程探测，不是已授权开放平台 API。遇到错误或非 JSON 即停止，不解决/绕过安全验证码。

本地仅用模拟响应验证 URL 白名单、正常提交流程、错误停止和不输出 randsk/Cookie；实际百度响应及下载尚待用户服务器执行确认。脚本不持久化 Cookie、不登录、不下载照片；只输出返回码、标题和列表线索。
