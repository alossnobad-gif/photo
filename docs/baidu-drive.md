### 配置与使用

1. 手动部署新版本，保留整个 .data 和现有服务配置。
2. 百度应用控制台登记 OAuth 回调： https://123.57.60.66/api/baidu/callback 。如果平台拒绝 IP 回调，需先确认控制台要求，不能假定已经登记成功。
3. 网站图库点击“百度网盘导入”，在 HTTPS 页面填 AppKey、SecretKey、同样的回调地址，保存。不得将密钥发聊天或源码。
4. 点击连接，浏览器到百度完成本人授权。回调返回图库并打开网盘窗口。
5. 输入目录，例如 / 或照片目录；读取列表，进入文件夹，分页选照片导入。导入后从图库明确选择识别物种或风光。

### 当前实现与边界

- 授权码流程、10 分钟一次性 state、令牌自动刷新、目录 100 条分页；列表只返回名称、路径、大小、ID，不返回下载地址/令牌。
- 凭据和令牌保存在 .data/baidu-drive.json（0600），加入受保护备份；不返回浏览器。保存配置清除旧连接。当前是个人账号，不作为多租户账号系统。
- 仅网盘读取接口；照片显式选择下载，150 MB 上限和磁盘空间检查；临时文件随机名，HTTPS 下载及重定向限制百度域名，失败清理。成功文件复用原有图库导入、日期/设备元数据、RAW 解码和中文名处理。
- 按远端文件 ID 对已导入记录去重；暂不检测云端同 ID 内容改变，个人工具不支持多人账号混用。
- 原件按当前图库策略保留；没有顺便批量压缩/清理已有原件。用户关于未来只保留压缩图的方案仍需独立实施。
- 清除本地连接移除本地令牌，不删除导入照片，不等于撤销百度端应用授权。授权中服务器重启需重新连接。
- 当前是手动读取目录/导入，不是持续后台同步。首次真实调用若 API 参数、回调、scope 或下载权限与当前百度要求不同，展示错误并在真实证据下调整。
