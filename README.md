# 自然图鉴

自然探险风格的照片物种图鉴。React + Vite 前端，Express 服务端；照片及收藏保存在 `.data`，示例素材为生成图片，不作为物种鉴定参考。

## 启动

需要 Node.js 22+。

```sh
cd /workspace/photo
npm ci --cache /workspace/.npm-cache
npm run dev
```

服务监听 `0.0.0.0:3000`。`npm run build` 构建；`npm start` 使用生产构建；`npm test` 验证首次解锁、重复保护及替换保留首次发现日期。

## 千问识别

在云环境设置中安全填写 `DASHSCOPE_API_KEY` 并重新启动服务。默认模型为 `qwen-vl-plus`，可通过 `QWEN_MODEL` 指定支持图片输入的千问模型。接口为中国区 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`；国际区密钥不能直接用于此接口。密钥只在服务端使用，不返回到浏览器。

缺少密钥时显示明确提示，并支持手动录入。照片发送到千问后产生候选结果，需要用户确认物种名称及学名才入库。不确定的识别结果需人工核实；稀有度是一般观测参考，不是保护等级。

## 收藏流程

上传 JPG/PNG/WebP（最大 12 MB）→识别或手动录入→确认→首次物种解锁。学名作为去重依据（忽略大小写及重复空格）；已有物种并排显示新旧照片，可保留或替换。替换保留原始 ID 和首次发现日期。`.data` 包含个人照片，请备份、保留。当前是单人云环境应用，无多用户登录系统。

## 网页识别设置

侧栏「识别设置」支持保存中国区 DashScope API Key 和视觉模型名称，保存后立即生效，无需重启。密钥输入留空会保留已有配置；填写则替换。接口只返回是否配置与模型名，不返回密钥。网页保存的配置优先于环境变量，保存在 `.data/recognition-settings.json`（权限 600），重启及更新代码后保留。该文件含密钥，不要上传 GitHub 或公开分享；备份 `.data` 时同样保护它。

当前单人部署依赖安全组限定访问来源；设置接口校验同源请求，但尚无账户登录。HTTP 不加密传输，请在可信网络使用并后续配置 HTTPS。保存成功不代表密钥权限、额度或模型调用已验证，应上传照片进行实际验证。

## 千问 AI 平台接入

`platform.qianwenai.com` 创建的密钥应选择「千问 AI 平台」，请求地址为用户提供的官方文档中的 `https://maas.qianwenaiapi.com/compatible-mode/v1/chat/completions`，图片示例模型为 `qwen3.8-max`。该平台与阿里云百炼为不同接口选项，不应混用密钥。切换平台时密钥留空保留原密钥，设置持久保存。旧配置继续使用 DashScope，需用户在设置中明确切换。只允许上述两个固定 HTTPS 目的地址。现有图片上传以 Base64 data URL 发送，用户文档示例只展示公网图片 URL；新平台真实调用与 Base64 支持尚待实际验证。

## 识别图片压缩

原始上传文件仍保存在 `.data/photos`，图库继续使用原图。调用模型前在内存中生成识别图片：自动校正 EXIF 方向，保持宽高比例，长边不超过 1600 像素，不放大小图，JPEG 质量 80，透明背景合成为白色。不裁剪主体；识别副本不额外写入磁盘。小图转换后若更大且不需要旋转，则保留原编码发送。使用 sharp，原生处理线程限制为 1；最大输入 8000 万像素。

测试照片 4000×3000 从 1,725,681 字节缩为 168,749 字节，原始字节未改变。压缩测试与既有设置/收藏测试共 7 项通过。服务器到模型的图片请求体积下降；手机上传原图的耗时及模型推理耗时并不保证同比下降。远处的小主体仍可能因缩图损失细节，尚未实现手动裁剪。

该更新新增 sharp 依赖，需要在拉取后运行 `npm ci`，测试通过再重启 `nature-photo`；前端未变更，无需重新构建。

## 模型请求超时

识别请求等待上限为 120 秒，回答上限 1200 tokens；超时、网络连接失败及不完整 JSON 分别显示明确提示，不自动重试产生额外调用。Nginx 应设置 `proxy_read_timeout 150s;`，避免在应用等待结束前关闭连接。既有 90 秒部署需要同步更新此值并经 `nginx -t` 后重载。延长等待不能保证模型提速或成功，需要在实际服务器上传图片复核。7 项既有测试通过，另以模拟上游 TimeoutError 验证实际识别路由返回 504、限制回答长度并保留原图。
