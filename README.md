# 自然图鉴

自然探险风格的照片物种图鉴。React + Vite 前端，Express 服务端；照片及收藏保存在 `.data`，示例素材为生成图片，不作为物种鉴定参考。

## 启动

需要 Node.js 22+。

```sh
cd /workspace/photo
npm ci --cache /workspace/.npm-cache
npm run dev
```

服务监听 `0.0.0.0:3000`。`npm run build` 构建；`npm start` 使用生产构建；`npm test` 验证首次解锁、重复保护及替换保留首次发现日期。

## 千问识别

在云环境设置中安全填写 `DASHSCOPE_API_KEY` 并重新启动服务。默认模型为 `qwen-vl-plus`，可通过 `QWEN_MODEL` 指定支持图片输入的千问模型。接口为中国区 `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`；国际区密钥不能直接用于此接口。密钥只在服务端使用，不返回到浏览器。

缺少密钥时显示明确提示，并支持手动录入。照片发送到千问后产生候选结果，需要用户确认物种名称及学名才入库。不确定的识别结果需人工核实；稀有度是一般观测参考，不是保护等级。

## 收藏流程

上传 JPG/PNG/WebP（最大 12 MB）→识别或手动录入→确认→首次物种解锁。学名作为去重依据（忽略大小写及重复空格）；已有物种并排显示新旧照片，可保留或替换。替换保留原始 ID 和首次发现日期。`.data` 包含个人照片，请备份、保留。当前是单人云环境应用，无多用户登录系统。

## 网页识别设置

侧栏「识别设置」支持保存中国区 DashScope API Key 和视觉模型名称，保存后立即生效，无需重启。密钥输入留空会保留已有配置；填写则替换。接口只返回是否配置与模型名，不返回密钥。网页保存的配置优先于环境变量，保存在 `.data/recognition-settings.json`（权限 600），重启及更新代码后保留。该文件含密钥，不要上传 GitHub 或公开分享；备份 `.data` 时同样保护它。

当前单人部署依赖安全组限定访问来源；设置接口校验同源请求，但尚无账户登录。HTTP 不加密传输，请在可信网络使用并后续配置 HTTPS。保存成功不代表密钥权限、额度或模型调用已验证，应上传照片进行实际验证。
